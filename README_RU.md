# Универсальный набор восстановления и оптимизации Xiaomi TV Stick 4K (MDZ-27-AA / soul)

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

[![Устройство](https://img.shields.io/badge/устройство-Xiaomi%20TV%20Stick%204K-orange.svg)]()

> Профессиональный открытый инструментарий для раскирпичивания **Xiaomi TV Stick 4K (MDZ-27-AA / soul)**, устранения циклической перезагрузки (бутлупа после неудачного OTA-обновления с Android 11 на 14), чистой прошивки обоих слотов A/B, полного удаления мусора (деблоата) и тонкой оптимизации скорости работы.

---

## 🚀 Основные возможности

* **⚡ Автоматический перехват стадий Fastboot:**
  Сам определяет **Стадию 1** (`amlogic` / первичный загрузчик) и переводит стик в полноценный режим **Стадии 2** (`soul`), устраняя ошибки `Variable not implemented`.
* **🛡️ Прошивка обоих слотов (A и B):**
  Прошивает все ключевые разделы (`bootloader`, `dtbo`, `oem`, `odm_ext`, `vbmeta`, `vendor_boot`, `boot`) сразу в оба слота (`_a` и `_b`), гарантируя, что устройство не окирпичится при аварийном переключении слота.
* **📦 Прошивка контейнера `super.img`:**
  Надежная заливка тяжелого динамического раздела (1.8 ГБ) с увеличенными таймаутами.
* **🧹 Корректное форматирование файловой системы:**
  Выполняет команду `fastboot -w`, создающую правильную файловую систему ext4 с метаданными (в отличие от `fastboot erase`, приводящего к зависанию на логотипе).
* **📶 Исправление бага со списком Wi-Fi:**
  Автоматически синхронизирует системные часы через ADB, возвращая отображение доступных сетей Wi-Fi в настройках.
* **🎯 Устранение бага пульта (контекстное меню «Открыть / Переместить»):**
  Отключает сервис Xiaomi `mitv.service` (`AccessibilityKeyService`), вызывающий задержку кнопки OK, и настраивает тайминги — приложения открываются мгновенно по обычному клику.
* **🚀 Безопасный деблоат (37 пакетов):**
  Отключает фоновую аналитику Xiaomi, трекеры, рекламные ленты PatchWall, скрытые автоустановщики и системный балласт без повреждения Google Play, Widevine DRM (работают Кинопоиск, Netflix 4K) и трансляций Chromecast.
* **📦 Умный установщик APK и бандлов (.apkm / .xapk):**
  Автоматически определяет архитектуру стика (`armeabi-v7a`), распаковывает сплит-бандлы APKMirror, отсекает несовместимые библиотеки и устанавливает через `adb install-multiple`.

## 🛠️ Требования к оборудованию

1. **Python 3.8+** на вашем компьютере.
2. **Android Platform Tools (`adb` и `fastboot`)**:
   * **macOS:** `brew install android-platform-tools`
   * **Linux (Ubuntu/Debian):** `sudo apt install adb fastboot`
   * **Windows:** Скачать официальный [SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) и добавить в переменную PATH.
3. **Питание и кабель:**
   > [!WARNING]
   > **Не подключайте стик через пассивные (неактивные) USB-хабы.**
   > В момент старта стик потребляет пиковый ток до 1.5А. При просадке напряжения операционная система компьютера аварийно отключает порт (`failed to create device 0xe00002bc`). Подключайте напрямую в порт ПК или используйте активный USB-хаб с собственным блоком питания. Подробнее в [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

## ⚡ Быстрый старт: Восстановление (Fastboot)

### 1. Скачайте и распакуйте прошивку
Скачайте официальный архив прошивки Android 14 (`mi-tv-stick-4k_14_26.6.10_91_MDZ-27-AA.7z`) и распакуйте его в папку `firmware/`:
```bash
mkdir -p firmware
7z x mi-tv-stick-4k_14_26.6.10_91_MDZ-27-AA.7z -o./firmware
```
*(Список обязательных образов смотрите в [docs/FIRMWARE_GUIDE.md](docs/FIRMWARE_GUIDE.md)).*

### 2. Подключите стик и запустите прошивку
1. Соедините стик кабелем Micro-USB с компьютером.
2. Если стик находится в циклической перезагрузке, перезапустите питание при подключенном кабеле.
3. Запустите скрипт восстановления:
```bash
python3 flash_recovery.py --firmware-dir ./firmware --lock
```

### Параметры `flash_recovery.py`:
* `--firmware-dir ПУТЬ`: Папка с распакованными файлами `.img` (по умолчанию: `./firmware`).
* `--lock`: Заблокировать загрузчик обратно после прошивки (возврат в заводское состояние).
* `--skip-super`: Пропустить прошивку `super.img` (полезно при быстром ремонте ядра или загрузчика).
* `--dry-run`: Тестовый прогон без реальной записи во флеш-память.

По завершении перезагрузите стик:
```bash
fastboot reboot
```

## 🚀 Оптимизация после прошивки (ADB)

После первой загрузки включите **Отладку по USB** (в меню *Настройки $\rightarrow$ Настройки устройства $\rightarrow$ Об устройстве $\rightarrow$ 7 раз нажать «Сборка»*, затем в *Для разработчиков $\rightarrow$ Отладка по USB*).

Запустите комплексный скрипт:
```bash
python3 optimize_stick.py --all
```

### Что делает скрипт:
1. **Синхронизирует время:** Исправляет баг, когда из-за сбитых системных часов в настройках не ищутся сети Wi-Fi.
2. **Исправляет меню на пульте:** Отключает `mitv.service` и настраивает задержку `long_press_timeout 800`, благодаря чему приложения открываются сразу, а не через меню «Открыть/Переместить».
3. **Отключает 24 пакета мусора:** Удаляет аналитику, рекламные баннеры PatchWall и бесполезные службы Xiaomi.
4. **Ускоряет интерфейс:** Ставит масштаб анимаций `0.5x` и отключает фоновые фоновые сканеры Wi-Fi/Bluetooth.

Вернуть отключенные пакеты можно в любой момент командой:
```bash
python3 optimize_stick.py --restore-debloat
```

## 📦 Установка приложений и APKM

Поскольку в Android TV скрыты телефонные приложения без ТВ-манифеста, используйте умный установщик (поддерживает обычные `.apk` и сплит-бандлы `.apkm` от APKMirror):

```bash
# Установка стандартного APK
python3 install_apk.py my_app.apk

# Установка бандла APKMirror (сам выберет архитектуру armeabi-v7a)
python3 install_apk.py ru.kinopoisk.tv_2.256.1.apkm

# Пакетная установка нескольких файлов
python3 install_apk.py ~/Downloads/*.apk
```
